# Contributing to KairosBoot

Thank you for contributing.

1. Fork the repository and create a focused branch.
2. Add tests for behavior changes.
3. Keep public C ABI changes backward compatible.
4. Open a pull request against `main`.
5. Address all review comments and wait for approval from `@EurekaRaider`.

Direct pushes to `main` are reserved for the repository owner. Do not include
unrelated formatting or refactoring in a feature pull request.
